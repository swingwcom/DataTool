How to Use the Data Dump Tool

1 — Browser Requirements

This tool uses the Web Serial API which is only supported in:

  • Google Chrome (desktop)
  • Microsoft Edge (desktop)

Safari, Firefox, and mobile browsers are not supported.

Firmware Requirement: This tool requires a Pro-Touch 5 running firmware version 5.1 or later. To update your scale, contact mike@swingw.com for the latest .bin files.

2 — Prepare Your Pro-Touch 5

  1. Connect the device to your computer using a USB cable — the device will power on automatically.
  2. Wait until the Home Screen is displayed on the device before proceeding.

3 — Connect

  1. Click the ⚡ Connect button.
  2. A browser dialog will appear listing available serial ports. Look for a port labeled USB Serial — that is your Pro-Touch 5. If you are unsure which port to select, unplug the device, note which ports are listed, then plug it back in and select the new one that appears.
  3. The status indicator will change to CONNECTED.
  4. The device may reboot briefly when the USB port opens — this is normal. Wait for the Home Screen to reappear before dumping.

4 — Dump Records

  1. Once connected, click ⬇ Dump Records.
  2. Make sure the device is on the Home Screen when dumping.
  3. Records will appear in the table one by one as they are received.
  4. Original saved clubs will remain on the Pro Touch scale.
  5. The Activity Log on the left shows transfer progress and any errors.

5 — Edit a Club Name

After dumping, you can rename any club directly in the table:

  1. Click on any name in the Club Name ✎ column.
  2. Type the new name.
  3. Press Enter or click away to save — press Escape to cancel.

Edited names are reflected immediately in CSV downloads and printed output.

Note: Name edits are made in this tool only — they are not saved back to the Pro-Touch 5 device.

6 — Download CSV

Click 💾 Download CSV to save all club records as a spreadsheet-compatible CSV file. The file will be named with the current date and time.

7 — Print

Click 🖨 Print to open your browser's print dialog. The page will automatically format for printing — all controls are hidden and only the club data table is printed. You can also choose Save as PDF from the print dialog.

⚠ Note: Club data is not stored by this tool — each session starts fresh. Always download or print your records before closing the browser tab.
